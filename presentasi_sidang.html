BAB I – PENDAHULUAN

Latar Belakang Masalah

🌶 Urgensi Komoditas

  • Cabai rawit (Capsicum frutescens L.) bernilai ekonomi tinggi dan strategis bagi petani
  • Kabupaten Magelang: lahan 3.828,9 ha dengan produksi 511.556,9 kwintal (BPS, 2023)
  • Permintaan tinggi dari rumah tangga & industri kuliner
  • Tanaman memerlukan: kelembapan 50–70%, pH 6–7, suhu 24–28°C

⚠ Permasalahan Lapangan

  • Pemantauan masih manual — petani harus datang ke greenhouse
  • pH tanah, suhu, dan kelembapan sering tidak stabil
  • Iklim lembap → risiko serangan jamur & OPT meningkat
  • Kerontokan bunga → penurunan produktivitas
  • Sistem monitoring yang ada tidak memiliki pengambilan keputusan otomatis
💡 Solusi: Sistem Pertanian Cerdas berbasis IoT + Fuzzy Tahani untuk pemantauan real-time dan pengendalian otomatis kondisi lingkungan greenhouse cabai rawit.

BAB II – LANDASAN TEORI

Landasan Teori

🌐

IoT

Jaringan objek fisik terhubung internet untuk akuisisi data, monitoring & pengendalian otomatis tanpa intervensi manusia langsung.

🔧

ESP32

Mikrokontroler dengan WiFi + Bluetooth terintegrasi. Prosesor dual-core 240 MHz, 520 KB SRAM. Pusat pengolahan data IoT.

📡

Protokol MQTT

Protokol ringan publish-subscribe untuk IoT. Latensi rendah, efisien bandwidth, cocok untuk sensor & perangkat berdaya rendah.

🧠

Fuzzy Tahani

Metode pengambilan keputusan fuzzy berbasis database relasional. Menggunakan query fuzzy + fire strength untuk keputusan adaptif.

🌡

DHT22

Mengukur suhu udara (−40°C~80°C) & kelembapan udara (0–100% RH)

🪱

Sensor Soil Moisture

Mengukur kadar air tanah via resistansi / kapasitansi. Dasar keputusan penyiraman otomatis.

⚗

Sensor pH Tanah

Mengukur keasaman tanah. Cabai rawit memerlukan pH optimal 6 – 7 untuk penyerapan hara efektif.

BAB IV – HASIL & PEMBAHASAN

Implementasi Fuzzy Tahani & Arsitektur Kode

Rule Base Fuzzy Tahani

RuleKondisiFire StrengthAktuator
R1IF Suhu Tinggiμtinggi(T)🌀 Kipas ON
R2IF Tanah Keringμkering(S)💦 Pompa Air ON
R3IF pH Asamμasam(P)🧪 Pompa pH ON
Threshold keputusan:
• Kipas ON jika μtinggi > 0.5
• Pompa Air ON jika μkering > 0.4 dan soil > 0
• Pompa pH ON jika μasam > 0.4 dan pH > 0
Logika Pompa (Timer):
• Pompa Air: nyala 10 detik → jeda 30 menit
• Pompa pH: nyala 10 detik → jeda 3 jam
• Manual mode → bypass semua jeda

Arsitektur FreeRTOS Dual-Core

Core 0 — TaskKomunikasi (Prioritas 1)
  • WiFi connect + NTP sync
  • MQTT TLS keep-alive + callback perintah manual
  • Publish data sensor ke broker tiap 15 detik
  • Insert Supabase REST API tiap 60 detik
Core 1 — TaskSensor (Prioritas 2)
  • Baca DHT22, Soil Moisture (Kalman Filter), Sensor pH (Kalman + drift-guard)
  • Inferensi Fuzzy Tahani → keputusan aktuator
  • tickPompa() tiap 20 ms — timer pompa auto & manual
  • Fast-path relay manual < 20 ms tanpa menunggu siklus sensor
Sinkronisasi: xSemaphoreMutex melindungi SharedData antar core · volatile ManualCmd untuk perintah instan
