## Kesimpulan: index.ino + index.html

Firmware: fuzzy Sugeno 3 jalur (suhu→servo paranet, tanah→relay air, pH→relay). DB: relay_paranet = flag servo, relay_air, relay_dolomit.

## Resistor & wiring (sesuai komponen di foto)

### DHT22 AM2302 (modul 3 pin + PCB)
- VCC → 3,3 V, GND → GND, DATA → GPIO4
- **Tidak perlu** resistor tambahan (pull-up ~10 kΩ sudah di PCB modul)

### Soil moisture (probe + modul 4 pin)
- VCC → 3,3 V (disarankan), GND → GND, **AO → GPIO35**, DO tidak dipakai
- **Tidak perlu** resistor di AO (pembagi sudah di modul + potensiometer)
- Kalibrasi: putar potensiometer modul, lalu sesuaikan DRY_VALUE / WET_VALUE di index.ino

### Sensor pH tanah + DMS
- DMS → GPIO13; analog pH → GPIO34
- Ukur tegangan AOUT dengan multimeter saat idle:
  - Maks ≤ 3,3 V → **tanpa** pembagi
  - Maks ~5 V → pembagi **10 kΩ** (atas ke sinyal) + **20 kΩ** (bawah ke GND) ke GPIO34

### Servo paranet (GPIO25)
- Sinyal PWM tanpa resistor; **5 V terpisah** + GND bersama ESP32; kapasitor **100–470 µF** di 5 V servo

### Relay air & pH (GPIO26, 27)
- Modul relay siap pakai: **tanpa** resistor di pin IN

### LED GPIO2
- Built-in board: tanpa resistor; LED eksternal: **220–330 Ω**

### DS18B20 (ada di foto, tidak dipakai di firmware)
- Suhu udara dari **DHT22**. Jika nanti pakai DS18B20: **4,7 kΩ** pull-up DATA ke 3,3 V

## Penjelasan diagram blok (`diagram_blok_sistem.png`)

Diagram dibuat dengan skrip Python `diagram_blok_sistem.py` (library Matplotlib). Gaya mengikuti contoh diagram TA: setiap kotak diberi nomor, panah menunjukkan aliran **daya** (abu-abu) dan **data/sinyal** (hitam/biru).

### Gambaran umum

Sistem ini adalah **greenhouse IoT untuk cabai rawit**. ESP32 membaca tiga parameter lingkungan (suhu & kelembaban udara, kelembaban tanah, pH tanah), memprosesnya dengan **fuzzy Sugeno tiga jalur terpisah**, lalu mengendalikan **servo paranet** dan **dua relay** (air & koreksi pH). Data dikirim ke cloud lewat **WiFi**: publikasi real-time ke **MQTT** dan arsip periodik ke **Supabase**; pengguna memantau lewat **dashboard web** (`index.html`).

Tidak ada LCD lokal atau notifikasi Telegram di firmware saat ini — penggantinya adalah dashboard berbasis browser.

### Aliran data (panah hitam / biru)

1. **Sensor → ESP32**  
   DHT22 (digital), soil moisture dan pH (analog via ADC). ESP32 mengumpulkan nilai mentah setiap siklus `loop()`.

2. **ESP32 → Fuzzy Sugeno (internal)**  
   Tiga fungsi terpisah:
   - `fuzzy_suhu` dari suhu DHT22 → keputusan servo paranet  
   - `fuzzy_soil` dari % kelembaban tanah → relay air  
   - `fuzzy_ph` dari pH → relay koreksi pH  
   Defuzzifikasi singleton; relay/servo ON jika skor ≥ 0,5.

3. **ESP32 → Aktuator**  
   Sinyal PWM ke servo; sinyal digital ke modul relay (active-low sesuai konfigurasi firmware).

4. **ESP32 → Cloud (WiFi, biru)**  
   - **MQTT**: payload JSON berisi sensor + `fuzzy_suhu`, `fuzzy_soil`, `fuzzy_ph`, `relay_paranet`, `relay_air`, `relay_ph` / `relay_dolomit`.  
   - **HTTPS → Supabase**: insert baris ke tabel `pertanian` dengan kolom yang sama.

5. **Supabase & MQTT → Dashboard**  
   Browser menampilkan nilai terkini (MQTT) dan kurva/tabel historis (Supabase).

### Aliran daya (panah abu-abu)

- **12 V** dari adaptor ke step-down dan (tergantung wiring) ke ESP32.  
- **5 V** dari step-down ke sensor yang membutuhkan 5 V.  
- **3,3 V** dari ESP32 ke DHT22 dan soil moisture (disarankan di firmware).  
- Servo idealnya **5 V terpisah** dengan GND common ke ESP32.

### Parameter optimal (konteks fuzzy)

Sesuai header `index.ino`: kelembaban tanah 50–70%, pH 6–7, suhu udara 24–28°C. Fuzzy memetakan penyimpangan dari kondisi ideal menjadi skor 0–1 per jalur.

Penjelasan diagram blok sistem monitoring dan kontrol greenhouse cabai rawit

ESP32 berperan sebagai pusat sistem: menerima data dari sensor (suhu & kelembaban udara, kelembaban tanah, pH tanah), memprosesnya dengan logika fuzzy Sugeno tiga jalur, mengendalikan servo paranet dan relay air serta relay pH, lalu mengirim data ke database Supabase (REST HTTPS) dan ke broker MQTT (WiFi) agar dapat ditampilkan di dashboard web.

Sensor pH tanah (beserta modul driver DMS) digunakan untuk mengukur derajat keasaman tanah di media tanam cabai rawit. Sinyal analog dibaca ESP32 melalui pin ADC (GPIO34), sedangkan pin GPIO13 digunakan untuk mengaktifkan modul DMS agar pembacaan pH stabil.

Sensor kelembaban tanah (soil moisture) digunakan untuk mengukur tingkat kelembaban media tanam. Modul probe menghasilkan sinyal analog pada pin AO yang dibaca ESP32 melalui ADC (GPIO35), kemudian dipetakan menjadi persentase kelembaban tanah (0–100%) untuk kebutuhan monitoring dan kontrol penyiraman.

Sensor suhu dan kelembaban udara (DHT22 / AM2302) digunakan untuk mengukur suhu dan kelembaban udara di dalam greenhouse. Data dikirim secara digital ke ESP32 (GPIO4) sebagai acuan kondisi lingkungan dan untuk jalur fuzzy pengendalian paranet (naungan).

Sensor pH tanah dapat tidak langsung menuju ESP32 jika keluaran modul masih berlevel 5 Volt—sinyal perlu melewati logic level converter atau pembagi tegangan terlebih dahulu agar masuk ke input ADC ESP32 yang aman pada 3,3 Volt, sehingga pembacaan lebih akurat dan perangkat terlindungi. Sensor DHT22 dan sensor kelembaban tanah pada umumnya langsung terhubung ke ESP32 (level 3,3 V) karena modul sudah sesuai dengan logika ESP32 dan pembacaannya stabil tanpa level shifter.

Logic Level Converter digunakan untuk mengubah level logika dari 5 Volt ke 3,3 Volt (atau sebaliknya) pada sinyal sensor analog/digital yang masih menggunakan tegangan 5 V, agar kompatibel dengan pin masukan ESP32.

Database (Supabase) digunakan sebagai penyimpanan data historis yang dikirim dari ESP32, berupa nilai sensor, skor fuzzy (fuzzy_suhu, fuzzy_soil, fuzzy_ph), dan status aktuator (relay_paranet, relay_air, relay_dolomit) pada tabel pertanian.

Sumber daya adaptor 12 Volt DC digunakan untuk memberikan daya ke seluruh sistem, termasuk ESP32 dan rangkaian pendukung sesuai skema instalasi greenhouse.

Modul DC-DC Step Down digunakan untuk menurunkan tegangan 12 Volt DC menjadi 5 Volt DC guna mensuplai perangkat yang membutuhkan 5 Volt DC, seperti beberapa modul sensor di lapangan.

Dashboard web (index.html) digunakan untuk menampilkan data secara real-time (melalui MQTT) dan riwayat data (melalui query ke Supabase). Pada sistem ini, peran tampilan lokal LCD digantikan oleh antarmuka berbasis browser.

Tambahan (aktuator dan komunikasi):

Servo paranet digunakan untuk menggerakkan naungan greenhouse berdasarkan hasil fuzzy suhu udara; dikendalikan melalui sinyal PWM (GPIO25).

Relay air digunakan untuk mengaktifkan pompa atau penyiraman ketika kelembaban tanah menurut fuzzy memerlukan penambahan air (GPIO26).

Relay pH digunakan untuk mengaktifkan larutan koreksi pH tanah ketika hasil fuzzy pH menunjukkan kebutuhan koreksi (GPIO27).

Broker MQTT (EMQX) digunakan sebagai saluran komunikasi real-time antara ESP32 dan dashboard web, sehingga pengguna dapat memantau kondisi greenhouse tanpa menunggu penyimpanan database saja.

Perbedaan utama dengan contoh air: di sistem Anda yang diukur adalah tanah dan udara greenhouse (bukan air), tidak ada sensor kekeruhan, dan tampilan memakai dashboard web + Supabase + MQTT, bukan LCD.
