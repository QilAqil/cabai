Logika Fuzzy dan Metode Fuzzy Tahani

Logika fuzzy adalah pengembangan dari logika biner. Logika biner hanya mengenal dua nilai, benar dan salah. Logika fuzzy memberi nilai keanggotaan pada rentang 0 sampai 1. Pendekatan ini membantu kamu menangani data yang tidak pasti dan berubah.

Konsep ini diperkenalkan oleh Lotfi A. Zadeh pada tahun 1965 melalui teori fuzzy set. Dalam teori ini, satu elemen bisa memiliki tingkat keanggotaan tertentu dalam suatu himpunan. Nilainya tidak hanya 0 atau 1, tetapi bisa di antara keduanya.

Logika fuzzy banyak dipakai dalam sistem pengambilan keputusan. Sistem ini cocok untuk bidang pertanian, ekonomi, dan sistem cerdas karena mampu mengikuti pola pikir manusia dan menyesuaikan kondisi nyata.

Metode dalam logika fuzzy terbagi menjadi beberapa pendekatan.

Fuzzy Inference System. Digunakan untuk proses penalaran dan pengambilan keputusan. Metode yang sering dipakai adalah Mamdani, Sugeno, dan Tsukamoto.

Fuzzy Clustering. Digunakan untuk mengelompokkan data berdasarkan derajat keanggotaan, contohnya fuzzy c-means.

Fuzzy Database. Digunakan untuk mengelola data yang bersifat samar dalam basis data. Salah satu metodenya adalah Fuzzy Tahani.

Metode Fuzzy Tahani adalah metode pengambilan keputusan berbasis fuzzy yang diterapkan pada basis data relasional. Metode ini menilai setiap data berdasarkan derajat keanggotaan. Sistem menggunakan query fuzzy yang strukturnya mirip Structured Query Language atau SQL. Dengan metode ini, kamu bisa mencari data menggunakan istilah linguistik seperti tinggi, rendah, atau sedang. Hasil rekomendasi menjadi lebih fleksibel dan sesuai tingkat kecocokan.

Tahapan dalam logika fuzzy model Tahani sebagai berikut.

Membership Function

Membership function adalah inti dari sistem fuzzy. Fungsi ini menentukan seberapa besar suatu nilai masuk ke dalam satu himpunan fuzzy. Nilainya berada pada rentang 0 sampai 1.

Kalau kamu punya nilai pH tanah 6,5, sistem tidak langsung menyebut netral atau asam. Sistem menghitung derajat keanggotaannya. Misal 0,7 pada netral dan 0,3 pada asam. Angka ini yang dipakai untuk proses berikutnya.

Fungsi keanggotaan biasanya ditentukan berdasarkan data lapangan, literatur, atau kebutuhan sistem milikmu.

Jenis Membership Function

Linear Naik
Nilai keanggotaan naik secara garis lurus.
Cocok untuk kondisi yang berubah bertahap.
Contoh pada kelembaban tanah.
Jika 30 persen dianggap kering dan 70 persen dianggap basah, maka nilai di antaranya naik secara proporsional dari 0 ke 1.

Linear Turun
Kebalikan dari linear naik.
Nilai keanggotaan turun dari 1 ke 0.
Cocok untuk kategori seperti sangat dingin yang berkurang saat suhu naik.

Kurva Segitiga
Bentuknya seperti segitiga dengan tiga titik, a, b, c.
Nilai naik dari a ke b lalu turun dari b ke c.
Banyak dipakai karena sederhana dan ringan dihitung.
Contoh suhu ideal cabai 24 sampai 30 derajat dengan puncak di 27 derajat.

Kurva Trapesium
Mirip segitiga tetapi bagian atasnya datar.
Ada rentang nilai dengan keanggotaan 1 penuh.
Cocok jika kamu ingin memberi toleransi nilai optimal.
Contoh pH optimal 6 sampai 6,8 dianggap sepenuhnya netral.

Kurva S atau Sigmoid
Bentuknya melengkung dan tidak linear.
Dipakai untuk perubahan bertahap yang tidak simetris.
Ada tiga parameter, alpha sebagai awal, beta sebagai titik tengah, gamma sebagai akhir.
Cocok untuk sistem dengan transisi halus seperti pertumbuhan tanaman.

Kurva Beta
Bentuknya seperti lonceng.
Dipakai jika kamu ingin fokus pada satu titik pusat dengan penyebaran tertentu.
Contoh tinggi tanaman ideal pada umur tertentu.

Cara Menentukan Membership Function

Agar hasil sistem milikmu akurat, lakukan langkah berikut.

Tentukan variabel input. Contoh pH, suhu, kelembaban tanah.

Tentukan kategori linguistik. Contoh rendah, sedang, tinggi.

Tentukan batas nilai berdasarkan data nyata. Misal pH cabai optimal 5,5 sampai 6,5.

Pilih bentuk kurva sesuai karakter data. Untuk sistem IoT seperti punyamu dengan ESP32, kurva segitiga atau trapesium lebih efisien karena ringan dihitung.

Contoh Sederhana

Jika kelembaban tanah 40 persen.
Kamu buat kategori kering 0 sampai 50 persen.
Kategori lembab 30 sampai 70 persen.

Hasilnya bisa seperti ini.
Derajat kering 0,2
Derajat lembab 0,6

Nilai ini masuk ke proses perhitungan fire strength untuk menentukan apakah pompa menyala atau tidak.

Semakin tepat kamu menentukan membership function, semakin akurat keputusan sistem milikmu.

Representasi Linear

Representasi linear memetakan input ke derajat keanggotaan dalam bentuk garis lurus.

Linear naik. Derajat keanggotaan bergerak dari 0 ke 1 seiring kenaikan nilai domain.

Linear turun. Derajat keanggotaan bergerak dari 1 ke 0 seiring kenaikan nilai domain.

Representasi Kurva Segitiga

Kurva segitiga merupakan gabungan dua garis linear. Nilai keanggotaan naik dari titik a ke b, lalu turun dari b ke c.

Representasi Kurva Trapesium

Kurva trapesium mirip segitiga, tetapi memiliki dua titik dengan nilai keanggotaan 1. Bentuk ini memberi rentang nilai penuh pada bagian tengah.

Representasi Kurva S

Kurva S atau sigmoid memiliki dua bentuk.

Pertumbuhan. Nilai keanggotaan bergerak dari 0 ke 1 secara tidak linear.

Penyusutan. Nilai keanggotaan bergerak dari 1 ke 0 secara tidak linear.

Kurva S memiliki tiga parameter, yaitu alpha sebagai titik awal, beta sebagai titik tengah atau infleksi, dan gamma sebagai titik akhir.

Representasi Kurva Beta

Kurva beta berbentuk lonceng dan lebih rapat dibanding kurva PI. Kurva ini memiliki dua parameter, yaitu gamma sebagai pusat kurva dan beta sebagai setengah lebar kurva.

Fuzzifikasi

Fuzzifikasi adalah proses mengubah nilai tegas menjadi nilai fuzzy. Nilai input dimasukkan ke dalam membership function. Sistem menghitung derajat keanggotaan untuk setiap himpunan fuzzy. Hasilnya adalah nilai fuzzy yang siap diproses pada tahap berikutnya.

Membuat Rekomendasi Keputusan

Setelah fuzzifikasi, sistem menghitung fire strength atau alpha predikat. Nilai ini menunjukkan tingkat kecocokan suatu data terhadap kriteria.

Operasi dasar yang digunakan mengacu pada operator Zadeh.

Interseksi atau AND. Sistem mengambil nilai keanggotaan terkecil dari dua himpunan.
μA ∧ B = min μA(x), μB(y)

Union atau OR. Sistem mengambil nilai keanggotaan terbesar dari dua himpunan.
μA ∨ B = max μA(x), μB(y)

Komplemen atau NOT. Sistem mengurangi nilai keanggotaan dari 1.
μ = 1 − μA(x)

Data direkomendasikan jika nilai fire strength lebih dari 0 sampai 1. Alternatif dengan nilai tertinggi menjadi pilihan utama karena paling sesuai dengan kriteria.

Fuzzifikasi Query

Fuzzifikasi query mengubah query konvensional pada DBMS menjadi query fuzzy. Sistem membentuk relasi dasar menggunakan operator AND, OR, dan NOT. Dengan cara ini, kamu bisa menghasilkan rekomendasi berdasarkan tingkat kecocokan, bukan hanya nilai pasti.
